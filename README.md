# Idea – Laravel Idea Management Application

A Laravel application for capturing, organising and managing ideas with authenticated user accounts, profiles, images and actionable steps.

## Features

- User registration, login and logout
- Authenticated idea management
- Create, view, update and delete ideas
- Idea image management
- Step/task updates linked to ideas
- User profile editing
- Route protection with Laravel middleware

## Technologies

- PHP
- Laravel
- Blade
- MySQL / SQLite
- HTML / CSS
- Git / GitHub

## What This Project Demonstrates

This project demonstrates a structured Laravel application using controllers, named routes, authentication middleware and resource-style CRUD operations.

The application separates responsibilities across controllers for ideas, images, steps, sessions, registration and user profiles.

## Main Application Areas

- `IdeaController` – idea CRUD operations
- `IdeaImageController` – image management
- `StepController` – idea step updates
- `RegisteredUserController` – registration
- `SessionController` – login/logout
- `ProfileController` – profile management
